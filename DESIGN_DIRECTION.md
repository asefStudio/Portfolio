# Design Direction

## 1. Project Identity

This website is not a traditional portfolio.

It is a personal product designer platform that represents a person who designs, builds, experiments and evolves.

The goal is not only to show previous work.
The goal is to communicate a mindset:

"Someone who does not only design products. Someone who creates what comes next."

The website should feel like a living identity, not a static resume.

---

# 2. Core Positioning

Primary identity:

Product Designer

Secondary identities:

- Creative builder
- Digital product explorer
- Physical product creator
- Technology enthusiast

The website should communicate that this person can move between:

- UX/UI design
- Digital products
- Emerging technologies
- Physical objects
- Creative experiments

---

# 3. Main Objective

The website should achieve three things:

1. Make people understand how this person thinks.
2. Show the quality of design execution.
3. Create curiosity about future projects.

The visitor should leave thinking:

"This person is building interesting things."

Not:

"This person is looking for a job."

---

# 4. Audience

Primary audience:

- Product Design Leads
- Creative Directors
- Founders
- Innovative companies

Secondary audience:

- Potential collaborators
- Creative communities
- People interested in technology and design

---

# 5. Personality

The website personality:

- Minimal
- Premium
- Intelligent
- Experimental
- Future-oriented
- Calm confidence

The feeling should be:

Apple + Figma clarity + Creative Studio mindset

Avoid feeling like:

- Generic agency
- Template portfolio
- Freelancer marketplace
- Resume website

---

# 6. Content Philosophy

Projects are not just screenshots.

Every project should communicate:

- Why it exists
- How the designer thinks
- What problem was explored
- What was learned
- What could come next

Focus on thinking, not only output.

---

# 7. KnotMatter Position

KnotMatter is part of the journey, not the main identity.

It represents:

- Physical product design
- Making and experimentation
- Creative entrepreneurship

It should appear naturally.

Do:

- Show selected physical products
- Link to KnotMatter when curiosity exists
- Mention it as another dimension of creation

Do not:

- Make the whole portfolio about KnotMatter
- Turn the site into an e-commerce presentation
- Make visitors think this is only a 3D printing brand

---

# 8. Future Vision

The website should suggest growth.

The visitor should feel:

"This person is not finished. Something bigger is coming."

Possible future direction:

- Creative Studio
- Digital products
- Physical products
- Experiments
- New technologies

The website should leave room for evolution.

---

# 9. Red Flags

Never do:

- Generic portfolio layouts
- Excessive project cards
- Empty design buzzwords
- "Passionate designer" style descriptions
- Looking desperate for employment
- Overusing animations without purpose
- Cyberpunk / gaming aesthetics
- Too many colors
- Trend-following without identity

---

# 10. Visual Rules

Priorities:

1. Typography
2. Layout
3. Motion
4. Interaction
5. Details

Motion should feel:

- intentional
- smooth
- premium
- calm

Never add animation only because it looks impressive.

---

# 11. Development Rules

Before changing code:

Understand:
- the current architecture
- existing components
- existing design language

Prefer:
- reusable components
- clean content separation
- scalable structure

Avoid:
- quick hacks
- duplicated code
- unnecessary dependencies

---

# 12. Decision Filter

Before adding any feature ask:

Does this make the website:

- more memorable?
- more premium?
- more aligned with a product designer identity?
- more future-proof?

If not, do not add it.
