# Portfolio Guidelines

## Project Vision

This website is not a traditional portfolio.

It should represent a product designer who is actively building, learning, exploring and evolving.

The visitor should feel:

"This person is not only showing past work. This person is creating what comes next."

---

# Core Positioning

The primary identity:

Product Designer

Not:
- UI designer only
- Freelancer portfolio
- Agency website
- Resume website

The website should communicate product thinking, craftsmanship and curiosity.

---

# Main Goal

Create a premium, memorable and living portfolio experience.

The website itself should feel like a product that evolves over time.

---

# Desired Feel

The experience should feel:

- Minimal
- Premium
- Editorial
- Calm
- Intentional
- Human
- Forward-looking

Avoid:

- Generic portfolio templates
- Dribbble-style designs
- Overly flashy animations
- Startup landing page feeling
- Empty marketing language

---

# Content Philosophy

Do not write generic portfolio phrases.

Avoid:

- "Passionate designer"
- "Creating meaningful experiences"
- "Solving problems through design"

The content should feel personal, thoughtful and specific.

---

# Narrative Structure

Current website structure:

1. Hero
2. Selected Work
3. Design Principles
4. About
5. Beyond the Screen
6. Contact

---

# Hero Purpose

The first screen should communicate:

- Who I am
- What I design
- That I am actively building and evolving

The feeling should be curiosity and confidence.

---

# Selected Work

Projects should demonstrate thinking, not only visual output.

The goal is to show:

- Product decisions
- Design process
- Problem solving
- Craft

---

# KnotMatter Position

KnotMatter is not the main identity of this website.

It should appear as an exploration of physical product design.

The hierarchy:

Product Designer
|
Digital Products
|
Physical Product Exploration

KnotMatter should create curiosity, not dominate the website.

---

# Motion Principles

Motion should feel:

- Intentional
- Smooth
- Premium
- Subtle

Reference feeling:

Apple-level restraint.

Avoid:

- Excessive effects
- Random animations
- Attention seeking motion

Every animation must support meaning.

---

# Responsive Principles

Every breakpoint should feel intentionally designed.

Do not simply shrink desktop layouts.

Desktop, tablet and mobile should each feel considered.

---

# Quality Standard

Target:

UI: 10/10
UX: 10/10
Motion: 10/10
Responsive: 10/10
Accessibility: 10/10
Performance: 10/10
Code Quality: 10/10

---

# Development Rules

- Keep components reusable.
- Keep content separated from UI.
- Avoid unnecessary dependencies.
- Prefer clean solutions over quick hacks.
- Do not change existing architecture without reason.

---

# Future Direction

The website should be able to grow with:

- Digital products
- Physical products
- Experiments
- Creative work
- Future studio projects

The website is a living product.
